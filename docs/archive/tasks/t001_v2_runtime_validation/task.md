# Task spec

## 背景

v2.3 计划要求先验证真实媒体与控制能力，再冻结架构、迁移数据及删除旧链路。当前已完成部分真实技术验证，完整矩阵仍有缺项；旧蓝图仍有单容器与控制租约设计。

## 契约区

### 范围

- 完成 docs/v2_architecture_plan.md 第18章17项的本地有效范围实验及可重跑验证资产；公网与原生Linux执行按最新用户指示豁免并明确未运行；独立审查结果，记录官方协议差异及实际平台限制。

### 非范围

- 不迁移用户数据，不删除旧运行路径，不发布外部服务，不以源码分析替代端到端媒体测试。

### 风险与回退

- 风险：官方 Selkies 协议、平台镜像和媒体实现可能与计划假设冲突；未测项禁止宣称通过。
- 回退：实验使用独立前缀容器、网络与 .scratch 文件，不挂载现有用户数据；失败保留证据，不切换正式运行链路。

### 依赖与约束

- Gemini 3.8 Flash 通过 OpenCode 派发；独立 worktree 并行实验；仅在 ~/kar/code 写文件，不生成公网凭证默认值。

### Finalization 时更新的 blueprint

- `docs/blueprint/architecture.md` 与 `docs/blueprint/testing.md`：在修订后有效范围验证完成、豁免项明确后更新架构结论与真实测试入口；不得把目标架构写成已实现生产能力。
