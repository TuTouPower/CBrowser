# Task spec

## 背景

Profile 预热/用户自检从 t068/p086 分出，共用本地探针不等于与发布门禁同次交付。默认不产生第三方访问，具体站点和预热范围仍需产品确认。

## 契约区

### 范围

- 用户显式启用的预热与自检使用该 Profile 网络视角，并给出时间、站点、配置版本/引擎与探针版本。
- 本地一致性、群体样本（若已有）与外部单站观测分开呈现；外部查询最小化，不主动外送凭据或完整指纹档案。

### 非范围

- 不把第三方 PASS 当 SLA，不新增 CDP/localhost 暴露；不实施仍在 p078 的强制代理，但不能绕过已配置代理。
- 不复活 parked p040；沿用 p060 本机 GeoIP/最小回显边界，外网不可达不妨碍本地自检。

### 验收标准

<!-- 规范（门禁必留，不得删除） -->

只写可观察、可独立验证的行为；每条使用稳定且不复用的 `AC-NNN`。需真实部署或人工环境验证时在编号前加 `[deploy]`。创建时均为未勾选（`- [ ]`）；实施验证通过后由实施 Agent 就地打勾（`- [x]`）；由 Review Agent 独立复核打勾真实性。技术选型不作为行为 AC。review 判 FAIL 且需修改交付内容时，实施 Agent 撤回全部打勾，修复并重验后重新打勾；reviewer 用 `TICK-VALID` / `TICK-VOID` 逐条判定。

<!-- /规范 -->

- [ ] [deploy] AC-001：未显式启用时无预热/检测第三方请求；启用后目标明确，只走选中 Profile 出口，不携带其他 Profile Cookie/凭据。
- [ ] AC-002：自检显示各观测来源、时间和配置/引擎/探针版本，缺测为不可判定；本地一致性、可用群体样本与单站结果分列，不以单站 PASS 显示整体通过。
- [ ] [deploy] AC-003：测试不开放新的本地端口或向 viewer 提供 CDP endpoint；取消/失败停止预热任务，不影响手动 Browser 会话与原状态。

### 可测试性声明

逐条说明不可自动测试的 AC 及替代验证；全部可测则写“全部 AC 可自动测试”。

- AC-001：需隔离真实 Docker/Chrome/引擎拓扑验收，可自动化但不可用 mock 替代；[deploy] 不授权生产发布。
- AC-002：可自动测试，触达生产函数或实际工具入口。
- AC-003：需隔离真实 Docker/Chrome/引擎拓扑验收，可自动化但不可用 mock 替代；[deploy] 不授权生产发布。
- 第三方公网站点属于需额外 opt-in 的人工补验；本地受控目标验证 AC，公网未执行标 NOT_RUN，不作 PASS。

## 上下文区

- 来源：2026-11-13 审阅复核：p086，经 t068 分出原 AC-005/006 自检部分；t068 提供本地测量，不需 persona 工厂存在才做单 Profile 自检。

### 有意不测

- 非范围中的新增产品功能不作为本 task 验收；已声明 AC 不豁免。

### 测试策略

- 默认不外发、取消与错误用本地受控站点自动测试；按 Profile 出口、代理失败不绕行、跨 Profile 凭据负向验证。
- 公网站点人工验收仅用户明确 opt-in 后执行，记录目标和外发数据；无公网条件不把外部检查标 PASS。
- 按 docs/blueprint/testing.md 的 doctor_cmd/test_cmd/blackbox_verify 执行；本次仅改 backlog，创建校验不代表实现验收。

### 未知契约清单

<!-- 规范（门禁必留，不得删除） -->

未核实的外部契约标为 `UNVERIFIED-BLOCKING` 或 `UNVERIFIED-SPIKE`；核实后改写为结论和验证方式。无则写“无”。

<!-- /规范 -->

- 是否实施预热、目标站点/访问频率/允许外发数据与默认入口：UNVERIFIED-BLOCKING，用户确认具体清单后 start；本批未授权向任何第三方站点发流量。

### 风险与回退

- 风险：跨模块/制品或状态变更需按上述负向测试与 spike 验证；产品 BLOCKING 未消除不得实施。
- 回退：回退本 task 的完整实现 release；涉及数据先停写者并从已验证成套备份恢复，禁止仅降级数据库或以旧兼容分支兜底。

### 依赖与约束

- 硬依赖和冲突以 progress.md 的 task.py 调度字段为准；不把文件重叠当硬依赖。plan 仅输出图上候选，不能替代 preflight；产品 BLOCKING 必须先确认，SPIKE 先验证并回填。

### Finalization 时更新的 blueprint

- docs/blueprint/security.md、docs/blueprint/testing.md、docs/blueprint/domain.md：显式外发与自检结论边界。
