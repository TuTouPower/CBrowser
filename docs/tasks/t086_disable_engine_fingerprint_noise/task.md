# Task spec

## 背景

新建美日环境在相同固定引擎上均产生 Canvas 和音频读值噪声告警。同 seed 的隔离对照实测关闭噪声后两项读值准确。

## 契约区

### 范围

- 将禁止引擎注入 Canvas、WebGL 和音频噪声确立为 Browser Runner 的统一启动策略。

### 非范围

- 代理出站 TCP、Windows 字体命名匹配、引擎升级、浏览器数据迁移及新增 UI 设置。

### 有意不测

- 第三方检测站评分与跨站群体统计：验收依赖本地受控输入和真实读值。

### 测试策略

- 先复现生产 Runner 缺少策略参数；通过正常启动入口采集 SDK kwargs，核对策略和既有身份入参；在真实固定引擎的本地页面比较固定棋盘像素和离线音频常量。

### 风险与回退

- 风险：读值策略变化导致旧指纹基线漂移，增加剩余原生指纹值的可观察性。以同配置重采验证，保留用户需要的隔离和种子行为。
- 回退：用上一个通过 readiness 的 release 回退。

### 依赖与约束

- 继续使用已批准的固定引擎制品、严格启动参数校验和现有出站策略。
