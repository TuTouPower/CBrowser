# Task spec

## 背景

ProfileForm按外部视口切三列，再将平台/字体、时区/语言、GPU/配色各嵌套半列；固定高度Select长文本越界。真实浏览器200代理候选撑到6418px，viewport的scrollHeight等于clientHeight，滚轮无法滚到末项。关联环境浮层、批量移动分组、低视口切换器和Dialog内时区菜单也已分别确认越界/裁切。

这些问题来自共享字段布局、候选容器高度和浮层交互契约缺失，应一次重构底座并迁移实际消费方。本task消费上游新身份配置与集合候选接口，交付完整新建/编辑表单与全站可增长候选可达性。

## 契约区

### 范围

- 按表单实际可用宽度规划基本、网络、指纹、高级分区；字段具有明确占宽，不在同一网格项内无规则嵌套半列；消除字体hash等无助录入的实现信息，消费上游已解析的字体/GPU/网页配色语义。
- 指纹种子使用六位数字适用的紧凑输入，刷新按钮放标签同一行；保持取值校验与刷新行为。长代理/分组名可识别且完整名称可访问。
- 固定少量枚举使用有界Select，代理/环境/分组等增长型实体使用可搜索选择；基于上游候选查询完整查找，选择身份不与显示/排序混用。
- 在共享Select/Popover/列表容器层统一可用视口、内部滚动、定位、焦点与键盘契约，保留既有Radix正确提交判据；时区候选处理Portal/碰撞与父容器裁切。
- 迁移ProfileForm创建/编辑、环境代理/分组筛选、代理国家/城市筛选、ProxyUsedByPopover、EnvironmentSwitcher与批量移动分组菜单，消除无限撑高与底部按钮堆叠。
- 全部高级布尔选项增加感叹号帮助：拟人化、自动启动、Google默认、透明代理、预览、剪贴板、第三方Cookie、恢复会话、便携Cookie；拟人化预设、启动参数和扩展路径同样有用途说明，hover/focus显示真实作用与限制。
- 必要尺寸/容器规则只改DESIGN.md源并生成token，保持深浅主题；复用现有Dialog滚动能力，保留已经正常工作的分组管理内部滚动。

### 非范围

- 不再次设计运行配置、GPU能力或CJK策略，不扩展集合后端分页协议，不实现删除生命周期或全站术语改名。
- 不以更换所有UI依赖、加宽一个弹窗或裁掉文字作为单独交付；不导航用户实际运行页面，不改用户环境数据。

只写可观察、可独立验证的行为；每条使用稳定且不复用的 `AC-NNN`。需真实部署或人工环境验证时在编号前加 `[deploy]`。创建时均为未勾选（`- [ ]`）；实施验证通过后由实施 Agent 就地打勾（`- [x]`）；由 Review Agent 独立复核打勾真实性。技术选型不作为行为 AC。review 判 FAIL 且需修改交付内容时，实施 Agent 撤回全部打勾，修复并重验后重新打勾；reviewer 用 `TICK-VALID` / `TICK-VOID` 逐条判定。

- [ ] AC-001：新建与编辑环境采用一致分区和字段对齐，依据弹窗实际宽度响应；普通/窄/低高度窗口及中英长文本下字段不重叠、不越出控件、不侵入相邻行，提交/取消可达。
- [ ] AC-002：种子输入紧凑且刷新位于种子标签行；六位合法值、刷新、手动修改与提交正确，未形成原先大空白输入与右侧漂浮按钮。
- [ ] AC-003：200代理与100分组/地区候选下，实际鼠标滚轮改变内部滚动，首末候选可达可选，搜索可找到未加载的末项，选中值准确回显。
- [ ] AC-004：100关联环境浮层、100分组移动菜单及环境切换器在常规和400px低视口中受实际可用视口约束，候选不跑到屏幕外；时区候选在Dialog内不被父滚动区裁切且可选择。
- [ ] AC-005：浮层打开、搜索、滚动、方向键/Home/End、Enter提交、Escape关闭与焦点回归正确，嵌套弹窗不误滚背景，鼠标同值重选只触发一次既有提交语义。
- [ ] AC-006：全部约定高级选项与额外参数字段旁有可访问帮助入口，鼠标和键盘均可读到当前界面语言说明，内容与实际运行行为一致。
- [ ] AC-007：已具备内部滚动的分组管理/外层Dialog保持末项与提交操作可达，长选中值有清晰展示与完整名称访问方式，深浅模式均可读。

### 有意不测

- 用户生产环境的实际破坏性操作：不执行；以隔离实例、可恢复副本与真实组件验证，不用生产数据造数。

### 测试策略

- 先以真实浏览器复现几何/滚轮失败，再覆盖生产组件全部增长型消费方；不把jsdom类名断言当几何通过。
- 0/1/100/1000元数据候选、200代理与100组特殊浮层，覆盖中英、长名称、窗口宽度/高度和缩放；读getBoundingClientRect、scrollHeight/clientHeight与真实滚轮结果。
- 组件测试验证搜索/选择ID、键盘、焦点、hover/focus帮助及同值提交；保持p070事件判据测试，语义失效旧布局测试整体替换说明理由。
- 运行design:lint、design:check、前端types/test/build与项目规定门禁；浏览器只用隔离mock与本轮拥有的测试实例。

- 风险：浮层Portal与焦点变化可能破坏选择提交或滚动锁；容器尺寸变化可能影响其他短枚举。帮助文字不得按名称猜测引擎行为。
