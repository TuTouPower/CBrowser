# Task spec

## 背景

独立 Linux arm64 探针没有提供当前 BrowserRunner 要求的字体资产。镜像检查通过后，链路和级别用例均在启动目标浏览器时因 `font_set_unavailable` 退出。

## 契约区

### 范围

- 独立探针预检、只读字体挂载、目标引擎共用快照，以及相关验证和操作文档。

### 非范围

- 生产字体配置、运行时启动契约和探针业务断言。

### 风险与回退

- 风险：合法的 Linux arm64 运行镜像仍需要当前引擎缓存与可读的内容寻址字体资产。
- 回退：回退测试夹具提交即可恢复之前的探针入口。

### 依赖与约束

- 复用正式字体 manifest 和已导入的 E2E 字体目录。探针容器不得写共享字体资产。

### Finalization 时更新的 blueprint

- `docs/blueprint/testing.md`：同步独立探针所需字体输入和挂载契约。
