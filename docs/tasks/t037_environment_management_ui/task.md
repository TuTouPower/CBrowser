# Task spec

## 背景

`docs/plan_20261105_ui_redesign.md` 第 5.3、5.4、5.5、5.8 节（用户 2026-11-05 确认）：首页改为环境列表，新建环境用弹窗，环境详情分为配置、文件、自动化、维护四个标签，并提供分组管理弹窗。新建弹窗与详情配置标签共用同一套配置表单，放在同一 task 内设计。2026-11-05 于 main@3101540 核实现状：`features/profiles/ProfileNewPage.tsx`（180 行）、`ProfileDetailPage.tsx`（640 行，含配置表单、复制、重置、删除，并用 `scopeMutationToProfile` 按 Profile 隔离动作状态）、`features/artifacts/ProfileFilesPage.tsx`、`features/automation/ProfileAutomationPage.tsx`。t036 已把这些组件临时挂在新路径，t035 已提供 Group、Proxy、活动时间与 409 删除语义。

## 契约区

### 范围

- 环境列表 `/`：
    - 工具栏：搜索（名称、备注、代理名）；状态筛选（全部、运行中、已停止、异常）；分组筛选（全部、未分组、各分组，底部「管理分组…」）；代理筛选；列表 / 卡片切换（存 `cbrowser.environments.layout`）；排序（手动顺序、名称、最近活跃、创建时间）；主按钮「新建环境」。
    - 筛选与排序状态放在 URL 查询参数中。
    - 列表列与卡片内容按 plan 5.3；卡片缩略图位在无预览时显示占位（缩略图由 t040 交付）。
    - 批量操作浮动条：启动、停止、移动到分组、删除。
    - SSE `runtime_state` 增量合并；无环境、筛选无结果两种空状态。
- 新建环境弹窗：分区为基本、网络、指纹、高级（默认折叠）；提供「创建」与「创建并启动」。
- 环境详情 `/profiles/:profileId/{config,files,automation,maintenance}`（`/profiles/:profileId` 重定向到 `config`）：页头含名称、状态、分组，以及打开会话、启动 / 停止；默认搜索初始化失败提示（含重试）与运行配置待应用提示（含「应用并重启」）在四个标签共享。
- 配置标签与新建弹窗共用一个配置表单组件。
- 文件、自动化标签：把现有 Artifact 管理、自动化状态与人工 / Agent 控制面板迁入并换皮。
- 维护标签：复制（仅配置 / 含浏览器状态，运行中禁用后者）、重置（列出将清除与保留的内容）、删除。
- 分组管理弹窗：列表（色块、名称、使用环境数）；新建、改名、改色（8 色调色板）、拖动与键盘排序、删除（确认框显示受影响环境数）。
- 删除被替换的旧页面组件及其测试，并移出颜色门禁豁免清单；在新页面结构下补齐隔离语义测试。
- 新增与改动文案 en / zh 同步补键。

### 非范围

- 代理库页面（t038）、会话页（t039）、缩略图内容（t040）。
- 指纹平台字段与平台字体状态展示（t041）。
- 自动化令牌管理 UI。
