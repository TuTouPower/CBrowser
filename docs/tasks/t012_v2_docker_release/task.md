## 契约区

### 范围

- 面向当前Mac的OrbStack/Docker与同机Chrome交付；正式compose/五服务镜像、Caddy/coturn配置、CI前后端/Chrome/Docker集成、多架构发布流水线及Docker+Chrome完整部署/迁移/备份文档；发布目标环境和凭据必须明确，不推送或部署到猜测目标。

### 非范围

- 不越过前置验证门禁，不静默缩减计划或改写验收标准；不处理与本阶段无关重构，不覆盖未获具体授权的用户数据或外部环境。
