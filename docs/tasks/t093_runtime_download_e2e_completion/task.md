# Task spec

## 背景

全量 E2E 曾把 Chrome 生成的空 `.crdownload` 文件当成完成产物。另一个下载用例保存目录首文件路径，再验证转发删除路径，也受 Chrome 临时文件重命名影响。

## 契约区

### 范围

- 真实下载捕获及重连用例、下载转发及重启对账用例。

### 非范围

- 生产下载逻辑、镜像和协议。
