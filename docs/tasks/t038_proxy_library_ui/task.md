# Task spec

## 背景

`docs/plan_20261105_ui_redesign.md` 第 5.7 节（D3，用户 2026-11-05 确认）：代理改为独立代理库，Profile 引用代理。t035 已提供代理 API（密码只写、`has_password`、`used_by_count`、409 `proxy_in_use`）以及带认证 SOCKS5 的 spike 结论；t036 已把 `/proxies` 设为空状态页；t037 的环境列表支持按代理筛选的 URL 参数。

## 契约区

### 范围

- `/proxies` 代理库页面：
    - 工具栏：搜索（名称、host、地区）、协议筛选、主按钮「添加代理」。
    - 列：名称、协议、地址（`host:port`，mono）、认证（有 / 无）、地区（国家码 + 标签）、使用环境数、操作（编辑、删除）。
- 添加 / 编辑弹窗：
    - 字段：名称、协议（http / https / socks5）、host、端口、用户名、密码、国家码、地区标签、备注。
    - 密码只写：编辑时显示「已设置，留空不修改」，并提供「清除密码」。
    - 「从 URL 粘贴」：解析 `scheme://user:pass@host:port` 并填入各字段。
- 带认证 SOCKS5 的表单行为与 t035 的结论一致。
- 删除：被引用时按钮禁用，并提示先改绑；处理后端 409。
- 使用环境数链接到按该代理筛选的环境列表。
- 新增文案 en / zh 同步补键。

### 非范围

- 代理连通性与出口 IP 检测（p040 已暂搁）。
- 代理 API 的变化（t035）。
