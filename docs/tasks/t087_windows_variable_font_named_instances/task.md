# Task spec

## 背景

使用已验证 Windows 11 字体集的环境无法在网页中按名称解析 Segoe UI Variable 的 Text 与 Display 命名实例。真实文件包含这些实例，当前 Linux 字体配置只按通用族公开。

## 契约区

### 范围

- Windows Profile 的两种可变字体名称匹配使用原字体真实光学尺寸实例，保留现有字体隔离。

### 非范围

- 原始字体文件变更、字体集默认绑定变更、噪声策略和代理 TCP 特征。

### 风险与回退

- 风险：过宽的匹配规则可能选中错误光学尺寸，或影响其他平台，验收需包含其他字体和平台限制。
- 回退：用上一个通过 readiness 的 release 回退，官方字体集及 Profile 数据保持原样。
