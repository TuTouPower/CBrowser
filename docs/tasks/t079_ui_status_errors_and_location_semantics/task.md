# Task spec

## 背景

测速错误码在表格、卡片、代理编辑弹窗原样显示；状态映射与词条在多个页面分别维护，工作台下拉同时有前置状态点与右侧徽标，长名称使运行中换行。国家/城市候选继承接口顺序，国家代码被作为字母徽标呈现。

根因是实体身份、业务语义、排序与本地化展示没有明确边界。本task交付统一的呈现语义及全部实际消费方，合并错误本地化、状态信息去重和地区呈现，不拆成逐页面微任务。

## 契约区

### 范围

- 建立唯一代理探测错误呈现映射：稳定机器码用于诊断，已知码对应准确中英说明，缺失/未知码回退通用失败说明；表格、卡片、编辑弹窗与相关提示复用。
- 按业务领域统一环境运行状态、传输状态、代理可用性描述；对象名、动作词、状态词分别规范，覆盖列/字段/按钮/选项/确认/帮助/Tooltip/可访问名称与全站中英词条，清理重复键与英文对象中的中文残留。
- 工作台环境下拉保留前置状态灯和名称，移除每项右侧重复徽标，并提供非颜色依赖的可访问状态说明；顶栏保留状态但环境运行中缩为运行中，其他环境状态同样采用统一短文案，传输状态仍独立可辨。
- 消费上游稳定地区标识与候选范围；国家使用标准代码作为身份、名称/国旗作为呈现、规范英文名称作为国家A-Z排序键。城市使用所属国家内的规范名称执行稳定字母排序；非拉丁名称使用明确本地化排序规则，不能按国旗或接口顺序排列。全部项固定首位。
- 列表、卡片及有国家前缀的筛选候选统一显示国旗和名称；未知代码不伪造国旗，保留统一占位与可访问名称。界面语言切换不改变筛选身份。
- 按既有i18n与设计系统实现少量明确的语义映射/呈现组件，不增加独立文案服务；错误API和存储中继续保留语言无关机器码。

### 非范围

- 不重写代理网络探测、在线GeoIP来源或运行状态机，不再实现集合分页/引用计数，不改网页color_scheme或删除生命周期。
- 不把不同领域的绿色状态都叫运行中，不为消除重复徽标移除顶栏传输信息，不改用户真实代理或环境配置。

### 验收标准

只写可观察、可独立验证的行为；每条使用稳定且不复用的 `AC-NNN`。需真实部署或人工环境验证时在编号前加 `[deploy]`。创建时均为未勾选（`- [ ]`）；实施验证通过后由实施 Agent 就地打勾（`- [x]`）；由 Review Agent 独立复核打勾真实性。技术选型不作为行为 AC。review 判 FAIL 且需修改交付内容时，实施 Agent 撤回全部打勾，修复并重验后重新打勾；reviewer 用 `TICK-VALID` / `TICK-VOID` 逐条判定。

<!-- /规范 -->

- [ ] AC-001：代理表格、卡片与编辑弹窗对同一已知测速失败显示一致、准确的当前语言说明；切换语言立即更新持久结果，未知/缺失码有本地化兜底，主状态不直接泄露机器码。
- [ ] AC-002：所有环境状态在列表、卡片、详情、工作台、入口及自动化中采用一致业务词汇；未加载/未知状态明确呈现，不回退为原始枚举或伪装成已停止，传输与代理状态语义仍可区分。
- [ ] AC-003：工作台环境下拉每项没有右侧重复状态徽标，保留前置状态点、可识别名称和可访问说明；顶栏中英运行态分别为运行中/Running，其余状态使用同一词汇体系。
- [ ] AC-004：国家和城市候选按明确名称规则稳定排序、去重，全部项首位；数据返回/新增顺序变化不改变排序，切换国家正确更新城市范围，中英切换不改变选中实体。
- [ ] AC-005：代理列表、卡片和有前缀的候选使用对应国旗与名称替换字母代码徽标，未知国家使用一致占位；国旗不承担筛选身份且可访问名称完整。
- [ ] AC-006：全站可见标签、操作提示、帮助及可访问文案的中英键完整，同业务语义不出现冲突措辞；长名称和窄窗口下状态信息不重复挤压，深浅模式可读。

- 用户生产环境的实际破坏性操作：不执行；以隔离实例、可恢复副本与真实组件验证，不用生产数据造数。

### 测试策略

- TDD 覆盖已知/未知/缺失错误、三处呈现一致性、语言切换、五态/未知映射和中英文词条集合；旧测试若断言原始error code或环境前缀，整体替换并说明新语义来源。
- 地区测试使用乱序/重复/大小写/同名城市/非拉丁名/未知代码夹具，断言稳定排序与值身份；表格、卡片、筛选三处有相同呈现。
- 真实浏览器用长名称与窄窗口检查工作台下拉徽标去重及状态说明hover/focus；组件测试验证导航、搜索与语言持久结果重绘。
- 运行前端types/test/build、design门禁与项目规定检查；仅mock代理观测，不访问或修改真实节点。

### 风险与回退

- 风险：统一文案时可能错误合并不同领域语义，切换国家标识可能丢失筛选，状态灯去重可能损失辅助访问能力；必须以业务概念和稳定ID验证。
- 回退：在隔离夹具验证全消费方后提交，失败回退同一实现commit；不恢复原始机器码作为主文案，不以中文别名兼容旧筛选身份，不删除诊断机器码。
