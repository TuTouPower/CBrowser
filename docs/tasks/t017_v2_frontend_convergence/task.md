# Task spec

## 背景

2026-11-02 intensive review（docs/reviews/review_20261102_201727）发现前端仍保留约 2900 行入口不可达的 v1 树（两套登录页、设置页与 API 客户端并存），v2 外壳与客户端存在用户可见缺陷与健壮性缺口（未定义色板、启动失败无提示、编辑被后台刷新覆盖、无超时、幂等键失效、跨源可携带凭据等），生成产物入库、路由依赖重复。用户以“最好的架构、最少的技术债”为标准全部采纳。

## 契约区

### 范围

- 删除 v1 前端树及其测试、类型声明、重复资源、仅 v1 使用的 i18n 键与仅被其引用的依赖（A46，用户决策 A）。
- v2 外壳与 profiles 页面缺陷修复；共享 API 客户端与 SSE 客户端加固；i18n 一致性。
- 生成产物移出版本库，路由依赖收敛为单一包。

### 非范围

- 不改 features/browser-session（归 t015）；不改后端与 OpenAPI 契约（归 t016，本 task 消费其生成类型）；不做 E2E 测试体系整改（归 t018）。
