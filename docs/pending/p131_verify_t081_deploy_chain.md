## 要验证什么

t081 AC-009（[deploy]）的真实环境部分，云端无 Docker Engine 不可执行，
按用户 2026-11-18 裁定延期本地统一补验：

1. 在隔离的真实容器化 Supervisor 链路（Mac 本地栈）导入现场规模或更大
    的合法字体集合（≈143 文件 / 362 MB 级），确认导入→接管→目录记录
    verified 全程可用。
2. 多个 Profile 共用同一已发布集绑定启动，完成启动验证后持续读取状态
    10 分钟：API 侧字体正文读取为零（以进程 rchar / 审计日志留证），
    实际 Browser 的集合身份（挂载 subpath 与 fc-list 结果）与目录记录
    一致。
3. 审计负例（删文件/改内容/加额外文件）使集标记不可用并阻止新启动；
    受控修复正例（重导入 + 审计）恢复可用，两者均留证。
