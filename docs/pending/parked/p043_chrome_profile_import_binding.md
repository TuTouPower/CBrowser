# p043 导入本机 Chrome 数据为 Profile 并绑定 Chrome 一键重复导入

- 来源：用户提出
- 内容：允许用户把本机 Chrome 的全部数据导入，作为 CBrowser 的一个 Profile（环境）；并允许把该 Chrome 与这个 Profile 绑定，绑定后用户点「导入」即自动把 Chrome 的所有数据导入到这个环境。当前用户明确暂搁（parked），不实施。
- 处理：不办

## 用户口述的功能点

- 一键把本机 Chrome 的数据整体导入，生成一个 CBrowser 环境（Profile）。
- 支持把这个本机 Chrome 与某个环境绑定；绑定后每次点「导入」，自动把该 Chrome 的全部数据导入到这个环境（持续/重复导入，非一次性）。
- 参考 ego lite 浏览器（用户口述，可行性未验证）：点一个按钮即可从 Chrome 导入数据，即使 Chrome 正在运行也能导入密码、插件、当前正在打开的网页、标签页等所有数据。
- 暂搁：用户明确指定暂搁（pending parked），暂不实施；立项时再评估
