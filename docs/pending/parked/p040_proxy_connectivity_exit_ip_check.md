# p040 代理连通性与出口 IP 检测

- 来源：用户提出
- 内容：代理库（UI 改造计划中新增的独立 Proxy 实体）上线后，为代理条目提供连通性检测（握手成功与否、延迟）与出口 IP / 地理位置查询，用于代理页展示与环境启动前自检。难点：探测必须走与 Profile 相同的网络路径与网络策略（Browser 默认拒绝私有与保留地址，代理按解析地址与端口例外放行，见 `docs/blueprint/supervisor.md`「网络策略与启动门禁」），不能从 API 进程直接发起，否则结果与真实出口不一致且绕过隔离；出口 IP 查询依赖外部 IP 回显服务，需评估隐私与指纹关联风险。依赖代理库先落地。
- 处理：不办
- 暂搁：用户要求暂搁，代理库落地后再评估
- 进展（2026-11-11，t052）：出口 IP / 地理位置部分已并入 t052 实现（Supervisor 在 Browser 同视角的 helper 内探测出口 IP、本机 GeoLite2 判定国家，见 `docs/blueprint/decisions.md` ADR 029）；连通性检测（握手成功与否）与延迟检测仍暂搁，继续 parked。
