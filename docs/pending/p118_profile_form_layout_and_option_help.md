# p118 环境新建编辑表单布局溢出、重排与选项说明

- 来源：2026-11-17 用户口述与新建环境截图；`pending-record` 后台 `bug-to-pending` analysis-only。
- 现象：新建环境中语言、字体集、配色方案文本在固定高度选择框内多行换行并越界；字体集名称附 8 位标识使控件更拥挤。平台与字体、GPU 与配色各挤在三列网格中的半列，其他字段却占整列，行列密度失衡。编辑环境共用相同表单。
- 影响：环境创建、编辑参数难以阅读，文本越出边框并侵入相邻行；改变窗口宽度或 UI 缩放后，按视口断点维持多列会继续压缩弹窗内字段。复现已确认字体、语言、配色三项；不将其余 Select 消费方未经复现的情况算作确定缺陷。
- 根因：产品布局缺陷。`ProfileForm.tsx:171-178` 的 `Section` 统一使用 `grid-cols-1 md:grid-cols-2 lg:grid-cols-3`，按视口宽度切列，未考虑弹窗实际可用宽度；`:502`、`:659`、`:815` 又把时区/语言、平台/字体、GPU/配色分别包成单个 `flex gap-sm` 网格项，每项内两个 `Row` 继续分列。`Row`（`:127-146`）使用 `flex-1`，缺少独立字段跨度与收缩策略。`shared/ui/Select.tsx:76-88` 的 Trigger 固定 `36px` 高度，Value 文本没有单行、溢出或截断策略，长文本按默认 `white-space: normal` 换行，超出高度仍可见。`ProfileForm.tsx:292-297` 又把字体集显示名称与 `set_id.slice(0, 8)` 拼进同一选项标签，加剧触发器换行。创建与编辑弹窗均设置 `size="lg"`，对应 `44rem` 最大宽度，外部视口进入 `lg` 不代表弹窗能承载三列及嵌套半列。
- 同类扫描：已确认新建与编辑共用 `ProfileForm`；已确认同表单三处嵌套分栏、共享 Select 的字体/语言/配色选中值越界。已检查 `ProxyFormDialog`、`SettingsPage`、`EnvironmentListToolbar`、`ProxyListToolbar` 的 Select 消费：没有确认相同固定三列内嵌两列机制，长分组/代理/国家城市名称仍属共享组件潜在风险，实施时补长文本验证，不宣称已复现。
- 测试缺口：`vitest.config.ts` 使用 jsdom，不执行真实 CSS 排版。`ProfileForm.test.tsx` 当前覆盖字体选择、语言联动、seed 刷新、布尔默认值与提交；Select 测试覆盖 pointer/keyboard 提交语义，均不能发现文本框几何越界。缺少创建/编辑弹窗不同宽度、中英界面、长字体名称的真实浏览器布局断言；缺少帮助提示 hover/focus 与本地化验证。
- 线索：`.scratch/profile_form_layout_probe/probe.html`、`run.mjs`、`result.json`、`width_results.json`、`probe.png`。通过 ego-browser 真实 Chromium，加载当前生产构建 CSS，重建相关原样 DOM/class（不是完整应用 E2E）：视口 1280px，内容外框 896px 时字体值高 `60.75px > 36px`；外框 704px 时语言/字体/配色值高分别 `60.75/81/40.5px > 36px`，三项文字均超出触发器上下边界。可用 `ego-browser nodejs < .scratch/profile_form_layout_probe/run.mjs` 重新生成首组证据；宽度扫描结果保存于 `width_results.json`。用户截图作为完整应用现象证据，最小 DOM 复现仅验证布局机制。
- 处理：t077；resolution=transferred；reason=已核实根因、同类范围与验收契约，按用户授权聚合转交 t077（表单布局与长集合选择交互统一重构）；转办不表示实现完成

## 用户要求与后续验收方向

1. 新建、编辑环境统一重新规划分区、行列、字段宽度、对齐与响应式布局，按字段内容和弹窗可用宽度安排；不能只遮掉溢出文本了事。避免同一级字段无规则嵌套半列；清晰展示必需信息，移除无助于用户选择的字体 hash 等实现信息。
2. 指纹种子只占适合六位数字的紧凑宽度；刷新按钮移至“指纹种子”标签同一行，不再放输入框右侧。保持已有 seed 取值校验与刷新功能。
3. 高级布尔选项旁统一增加感叹号帮助：拟人化、自动启动、设 Google 为默认、透明代理、采集预览、剪贴板同步、允许第三方 Cookie、恢复会话、便携 Cookie。鼠标悬停或键盘聚焦显示当前界面语言说明，解释实际作用、适用条件及关键后果；说明必须核对后端/引擎实现，不能按字段名称猜测。拟人化预设、启动参数、扩展路径亦补相应用途说明，纳入统一帮助交互。
4. 真实浏览器分别打开创建/编辑表单，覆盖当前 lg 弹窗、窄窗口、中英界面、长选项文本，断言可见文字与图标不越出控件或遮挡相邻字段，选项菜单与键盘交互仍可用。seed 标签行布局、紧凑宽度、帮助提示 hover/focus、本地化均需对应行为验证。
