# p123 工作台移除重复状态徽标，并统一全站状态及操作文案

- 来源：2026-11-17 用户口述及工作台环境切换器截图；pending-record 普通需求登记。
- 内容：工作台环境选择已有前置指示灯，移除每项右侧重复状态徽标；顶栏“环境运行中”缩短为“运行中”；统一全站标签与可见文案。
- 处理：t079；resolution=transferred；reason=已核实根因、同类范围与验收契约，按用户授权聚合转交 t079（全站状态错误文案与代理地区呈现统一）；转办不表示实现完成

## 明确要求

1. 工作台环境切换器下拉列表每项保留前置状态灯、环境名称与选择/导航能力，移除右侧“运行中”等重复状态徽标。创建/编辑名称较长时不再因重复徽标挤占而出现“运行/中”换行。此要求覆盖所有运行状态，不仅运行中分支。
2. 保留指示灯状态含义的可访问说明，避免移除右侧文字后只靠颜色区分状态；可通过语义标签、辅助文字或聚焦/悬停说明呈现，不另加占宽的重复徽标。
3. SessionHeader 顶栏运行状态徽标保留，将“环境运行中”改成“运行中”，英文使用一致的 Running；对启动中、停止中、已停止、异常等环境状态同步采用全站统一短文案，避免只改 running 一个值而其他状态继续带重复主语。
4. 全站同业务含义采用同一文案：环境列表/卡片、环境详情、会话入口、工作台顶栏与切换器、自动化、代理管理、设置及相关弹窗/表单/提示。覆盖列名、字段名、选项、按钮、状态标签、帮助、确认、成功/错误提示、Tooltip 与可访问名称，中英界面同步。
5. 状态与操作分开规范：例如运行中是状态、启动是动作；同一业务概念使用稳定词汇，不把不同语义机械替换成同一句话。环境运行状态与传输状态、代理可用性仍须明确区分，不能因为共享绿色样式就都写成运行中。用户没有要求删除传输状态信息。
