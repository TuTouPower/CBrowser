# bundle_local_archive_spikes

## responsibilities

- s001: Selkies runtime baseline (Xvfb/PulseAudio/CloakBrowser loop, MIT-SHM probe, image manifest)
- s002: Selkies protocol probes (TURN auth, ICE restart, DataChannel restart characterization)
- s003: Selkies control plane (CDP-over-UDS proxy, cross-container downloads, supervisor/API recovery orchestration)
- s004: media connections E2E (multi-viewer HELLO/SESSION, audio+video real decode oracles)
- s005: capture policy (in-process policy agent, protocol armor, real + native-visibility E2E suites; revision_03 holds the retired suite)
- s006: standalone Gateway/Agent signaling tunnel with process-level SIGKILL recovery verification
- s007: dual-profile IPC/X11/PulseAudio isolation with strict audio metrology gates
- s008: TURN credential generation takeover on one PC (generation-commit fence adapter, adversarial one-sided-invalid matrix)
- s009: native Chrome composition -> Selkies input channel -> X11 -> remote DOM, clipboard untouched
- s010: CloakBrowser SDK process-exit observation (FD 3/4 pipe, exit codes, owner-loss characterization)
- s011 (live, docs/spikes/): direct loopback media matrix that justified removing TURN/coturn (t015); pytest against production-shaped runtime containers

## interfaces

- UDS control sockets: s003 agent.sock CDP proxy, s003 recovery container_agent commands, s005 /tmp/capture_policy_agent.sock (record_input/get_state)
- s008 auxiliary HTTP control API on 0.0.0.0:18092 (GET /health, GET /peers, POST /restart_ice)
- WebSocket gateway protocol: s006 envelope {type,conn_id,data} with Bearer agent registration; s011 re-implements a v2 variant in GatewayMockServer
- TURN REST ephemeral credentials (HMAC-SHA1, TTL 120s) generated by s008 probes from a shared static-auth secret file
- X11 (Xauthority cookie) and PulseAudio (cookie or anonymous) unix sockets shared via per-spike Docker volumes
- CDP bridges into the browser container (loopback /json + websocket Runtime.evaluate) used as test oracles in s005/s006/s009/s011

## dependencies

- Selkies 2.1.0 internals, including name-mangled private attributes (_RTCIceTransport__*, _RTCPeerConnection__iceTransports) in s005/s008 adapters
- CloakBrowser SDK 0.6.4 / Chromium 146 binary distribution (s001 runtime images reused by s006/s008/s009)
- coturn (s002 probes, s008 server; image referenced as coturn/coturn:latest in s008 start_coturn.sh)
- Docker + host Google Chrome at a hardcoded macOS path in s005/s006/s008/s009/s011 harnesses
- s011 only: production backend package (cbrowser.domain.models, cbrowser.gateway.endpoint via PYTHONPATH=src/backend) and tests/fixtures/stream_probe/* outside this unit

## flows

- Gateway tunnel: viewer WS -> gateway envelope -> agent per-viewer bounded queue -> upstream Selkies signaling (s006), with agent auto re-registration after gateway SIGKILL
- ICE generation takeover: prepare_restart gathers relay candidates -> zero-relay rejected pre-Offer -> start() commits, closes old connection, verifies send rejection -> fresh media baseline on the new pair (s008)
- Capture policy: peer visibility/input/motion signals -> single serialized reconcile_capture_state -> pause/resume + 8/30 FPS arbitration (s005)
- IME commit: CDP Input.imeSetComposition/insertText -> official client co,end message -> XTest typing in remote browser -> read-only CDP DOM oracle (s009)
- Exit observation: SDK -> controlled wrapper (FD 3/4 pass-through) -> real Chrome; /proc exe+starttime identity binding before reading exit status (s010)

## constraints

- Archive rule (docs/archive/spikes/README.md): snapshots are not runnable in place; copy to .scratch/<probe>/ on an isolated network/throwaway containers only
- All spikes are localhost/OrbStack arm64 scoped; public Internet, NAT traversal and native Linux x86_64 are explicitly out of scope or user-waived, and unrun items must not be counted as passes (range-update headers on archived reports)
- Fixed ports, container-name prefixes and single-run-at-a-time per spike; cleanup in finally blocks
- Raw run logs and evidence JSON live in the main repo's .scratch (outside this repository), so archived PASS claims are not independently re-checkable from the tree alone

## decisions

- Every archived spike report records adoption as 'yes, feasibility only' with production gates (17-item quality gate, AC-004 public part) explicitly left open
- s008: same-URL fixture wholly replaced by the split client/server TURN topology; old report retained as report_same_url.md, old sources retained only in main-repo scratch
- s005: old Core S10 suite retired intact into revision_03/ and replaced by the Native7 visibility suite rather than editing old expectations in place
- s011 adoption feeds t015: TURN/coturn and credential rotation removed for the single-machine deployment envelope
- Reviews' overreaching claims are repeatedly NOT adopted by the spike reports (s004 HELLO fidelity, s005 34.7ms latency inference, s007 R4 dB conversion, s009 Blink mechanism) - corrections live in report.md files

## evidence

- Independent reviews with SHA256 tables and real re-runs (exit codes, timings) accompany s005/s006/s007/s008/s009; s010 records a frozen source hash and pinned image ID
- No real secret values found anywhere in the 102 files: TURN/agent secrets are generated per run into 0600 files (s008 turnserver.conf, s011 secret files) or token files (s006); sentinel strings in s007 are synthetic test markers by design
- git check-ignore verified in this review: docs/archive/spikes/**/probe_work/ and docs/archive/spikes/**/*.secret cover the s008 secret/conf and s006 agent_token.secret paths
- s006 agent audit log contains only direction/category/size and truncated SHA256 - no payloads (run_agent_client.py _record_audit)
- Positive patterns: s002 negative TURN cases require the actual 401 error strings; s004 uses in-container CDP DOM oracles with exact counts; s007 R5 replaced a silently-skippable historical-binary negative with a mandatory dynamic rate-mismatch calibration

## uncertainties

- Static review only: no spike was executed, so all runtime PASS claims rest on the spikes' own recorded reviews and on logs stored outside this repository (.scratch), which were not re-verified
- s011's external fixtures (tests/fixtures/stream_probe/*, media_page.html, clipboard_oracle.py, web_lock_shim.js) and the production backend modules it imports are outside this unit's 102 files; they were assessed only at their call sites in direct_media_probe.py
- Upstream Selkies/CloakBrowser sources cited by reviews (e.g. pinned selkies input_handler commit in s009) are not part of this unit and were not read
- s001 image_manifest.json was read in full; it self-declares local/arm64 scope and does not prove reproducible builds - no other generated manifest required structure-level-only coverage

- [Low][85] docs/archive/spikes/s003_selkies_control/code/container_uds/container_cdp_probe.py:83 — s003 CDP-over-UDS proxy: orphaned listener task, unlocked re-arm race, unbounded event buffer
  - ID: f_archive_spikes_06; verification: static
