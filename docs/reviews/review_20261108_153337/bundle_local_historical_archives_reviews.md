# bundle_local_historical_archives_reviews

## responsibilities

- 承载系统工程演进的不可篡改历史凭证链（已闭环的 46 个 tasks 与 45 个 pending）
- 沉淀历史多路审阅报告（docs/reviews/）与技术调研结果（docs/spikes/）
- 维护历史任务单基线索引（tasks_index.json）与历史交接记录（handoff.md）

## interfaces

- docs/archive/tasks_index.json
- docs/archive/tasks/{tid}\_{slug}/
- docs/archive/pending/pNNN\_{slug}.md

## dependencies

- Git log / 提交历史
- Markdown 文档

## flows

- 归档流：已完成 task 由 integrate 自动移入 docs/archive/tasks/ -> 已解决 pending 由 pending.py archive 迁入 -> 过时 review/spike 由 repo_hygiene 迁入

## constraints

- 历史归档文件绝对冻结，严禁擅自修改已归档的 AC、代码审查或执行回执
- 归档调研脚本严禁在当前工作区就地运行，必须复制到 .scratch 隔离执行
- 历史交接记录仅允许增量追加，严禁截断

## decisions

- 废弃即归档，彻底保留从 legacy 向 v2 演进的架构决策轨迹
- 单基线 JSON 索引保证 O(1) 状态追溯
